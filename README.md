# E-Commerce Sales & Profitability Analysis

## Project Overview

An interactive Power BI project designed to analyze e-commerce sales performance, profitability, customer behaviour, product performance, and return trends.

## Dashboard Pages

### 1. Overall Business Performance

* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Unique Customers
* Total Quantity
* Monthly Sales Trend
* Sales by Category
* Sales by Sales Channel
* Profit by State

### 2. Customer Behaviour & Product Insights

* Repeat Customers
* Average Discount %
* Average Order Value
* Return Rate
* Total Returns
* Sales by Customer Segment
* Top 10 Products by Sales
* Repeat vs One-Time Customers
* Return Reason Analysis
